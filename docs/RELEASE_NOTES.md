# IncomeFlow verified testnet demonstration

IncomeFlow organizes supported crypto income into owner-selected spending, savings and reserve wallets using Reactive Omni. This release accompanies the original M1 and signed frontend acceptance evidence.

- Working app: https://incomeflow-gamma.vercel.app
- Film: 150 seconds, 1920×1080, 30 fps, H.264 video and AAC synthetic narration.
- Attachments: genuine moving demonstration MP4, sentence-timed subtitles and machine-readable verification report.
- Actual on-chain proof, addresses, source matches and both payment loops: [ONCHAIN_PROOF.md](https://github.com/sopskistar/IncomeFlow/blob/main/docs/ONCHAIN_PROOF.md).
- Internal audit and pre-submission checklist are in the repository. This is a testnet prototype, not an independently audited mainnet financial product.

The original and signed-user runs each received 100 valueless ifUSD and actually paid 50/30/20. The original live duplicate callback paid nothing extra. The film distinguishes the two runs and labels explanatory graphics. Edited screen timing is not a latency benchmark; the original two-second Base timestamp observation is a single result, not a guarantee.
